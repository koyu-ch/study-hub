跨章節知識整合與考前複習

作業與供應鏈管理／跨章節知識整合與考前複習

關鍵字 · 跨章節、考前複習、計算題

重點提示

整合各章觀念與考前練習，複習計算公式及應用。

第三部分:跨章節知識整合

1. 從生產方式到供應鏈策略

第一章的生產方式,與第六章的訂單履行策略具有直接關係。例如,少量多樣的產品通常需要較高的流程彈性,較可能採用工作式生產與 MTO;大量標準化 產品則較容易搭配重複式生產與 MTS。

但這不是絕對對應,企業仍需考慮產品特性、交期、需求不確定性與產能條件。

2. 從需求預測到庫存管理

需求預測與供應鏈管理形成一條重要的因果鏈:預測需求 → 決定採購與生產數量 → 形成庫存 → 滿足顧客訂單。

如果預測不準確,可能造成過量庫存或缺貨;如果供應鏈成員各自根據不完整資訊更新預測,也可能加劇長鞭效應。

因此,改善預測品質與提高資訊共享,都是供應鏈績效管理的重要手段。

3. 從營運策略到績效衡量

企業的策略優先事項會決定應該衡量哪些績效。這表示生產力雖然重要,但不能只追求生產力,而忽略企業真正的競爭策略。

營運策略                               重要管理指標舉例
低成本                                單位成本、生產力
高品質                                不良率、顧客滿意度
快速交付                               訂單交期、準時交貨率
高彈性                                產品切換時間、客製化能力
庫存效率                               存貨週轉與持有成本

4. 從預測到決策分析

需求預測與決策分析具有互補關係。預測方法用來估計未來需求;決策分析則用來比較不同方案在未來情境下的結果。

例如,企業考慮擴廠時:

1. 利用需求預測分析未來市場。

2. 建立高需求與低需求等自然狀態。

3. 估計各方案在不同狀態下的成本與報酬。

4. 若有合理機率,使用 EMV 或決策樹。

5. 選擇符合企業策略與風險偏好的方案。預測提供決策資訊,決策分析將資訊轉換成方案選擇。

第四部分:考前快速複習

1. 考前自我檢測

1. 為什麼少量多樣的產品通常較適合程序式配置?因為不同產品需要不同加工順序,程序式配置能提供較高的路線與設備使用彈性。

2. 單要素生產力提高,是否代表企業整體生產力一定提高?不一定。可能同時增加其他投入,應進一步比較多要素或總要素生產力。

3. Order Qualifier 與 Order Winner 最大差異是什麼?前者是取得顧客考慮資格的基本門檻,後者是促使顧客實際選擇企業的競爭因素。

4. Maximin 和 Minimax Regret 有什麼差異?Maximin 比較最差報酬;Minimax Regret 比較相對於各狀態最佳方案所產生的最大機會損失。

5. 決策樹為什麼要從右往左計算?因為前期決策的價值取決於後續可能結果,必須先評估終端報酬,再逐步回推。

6. 移動平均期數增加,會產生什麼效果?通常使預測更平滑,但對需求趨勢變化的反應可能較慢。

7. 指數平滑的 α 越大代表什麼?越重視最新實際值,對需求變化反應較快,但也更容易受短期波動影響。

8. 為什麼 VMI 可能有助於降低長鞭效應?供應商可以取得較直接的庫存與需求資訊,減少各層級反覆預測及訂購造成的資訊失真。

9. ATO 與 MTO 的差異是什麼?ATO 通常先備妥標準零組件,接單後組裝;MTO 則在接單後才進行產品製造。

10. 延遲差異化為什麼能降低庫存風險?因為企業先保留通用零組件或半成品,等需求較明確時才決定最終產品形式,減少特定成品庫存過剩。

2. 問答題

1. 為什麼企業不能只追求生產力最大化?請結合生產力、競爭力、Order Qualifiers 與 Order Winners 說明。

生產力衡量投入資源轉換成產出的效率,但競爭力還取決於品質、交期、彈性與顧客需求。Order Qualifiers 是企業進入顧客考慮範圍的基本條件,Order Winners則是讓顧客最終選擇企業的競爭因素。例如,企業雖透過大量生產降低成本,但若顧客更重視客製化與交期,仍可能失去訂單。因此企業應先確認市 場競爭需求,再決定要優先改善哪些作業績效。

2. 企業應如何根據產品的產量、客製化程度與市場需求,選擇生產方式、設施配置及訂單履行策略?

少量多樣且客製化程度高的產品,通常適合 Job Shop 與 Process Layout,並可搭配 MTO 或 ETO;大量標準化產品則通常適合重複式生產、Product Layout 與 MTS。

若產品使用共通零組件,但顧客需要不同組合,可採 Cellular Layout、ATO 或延遲差異化策略。選擇時應考慮產量、產品多樣性、交期、設備投資及存貨風 險,並非所有生產方式都有固定的一對一對應關係。

3. 請說明需求預測、決策分析與企業營運策略三者如何相互連結。

營運策略決定企業希望建立的競爭能力,例如低成本或快速交付;需求預測則估計未來需求,提供產能、採購與庫存規劃的資訊。決策分析進一步比較不同方 案在未來自然狀態下的報酬。若無法估計狀態機率,可使用 Maximax、Maximin 等準則;若能估計機率,可使用 EMV 或決策樹。最終選擇除了考慮期望報 酬,也應符合企業策略與風險承受能力。

4. 什麼是長鞭效應?請解釋其形成原因,並說明 VMI、資訊共享與需求預測如何改善這個問題。

長鞭效應指供應鏈上游的訂單或庫存波動可能大於最終顧客需求的波動。原因包括各層級獨立預測、批量訂購、價格促銷及缺貨時的過量訂購。

VMI 讓供應商根據零售端庫存與銷售資訊安排補貨,資訊共享則減少需求資訊失真。搭配較合理的需求預測與補貨制度,可降低不必要的訂單波動、庫存成本 與缺貨風險。

5. 請比較集中採購與分散採購,並說明企業應如何根據營運策略選擇採購制度。

集中採購由中央部門統一管理,優勢是集中議價、統一規格及控制採購成本,適合共通性高、大量採購的物料。分散採購由各部門或據點自行負責,優勢是能 快速回應當地需求,但可能犧牲議價能力與標準化程度。若企業重視低成本與規模經濟,可偏向集中採購;若重視市場回應速度與在地彈性,可偏向分散採 購。實務上也可依物料特性採混合制度。

3. 計算題

1. Naïve 天真預測法

公司 1 月至 5 月的實際需求分別為 120、135、128、150、160 件。使用 Naïve 方法預測 6 月需求,並說明其預測邏輯。使用公式 F_{t+1}=A_t

• Naïve 方法直接使用最近一期的實際需求,作為下一期的預測值。

• 5 月實際需求為 160 件。

• 因此,6 月預測需求 F6 = A5 = 160 件。

觀念提醒:Naïve 不需要計算平均,也不會自動調整趨勢;直接取上一期實際值即可。

2. 簡單移動平均法

某產品最近 6 個月的實際銷量為 100、120、110、130、150、140 件。請分別使用 3 期與 4 期移動平均法,預測第 7 個月的需求,並比較兩者差異。使用公 式 F_{t+1}=\frac{\sum_{k=0}^{n-1}A_{t-k}}{n}

• 3 期移動平均:取第 4、5、6 月的 130、150、140。

• F7 = (130 + 150 + 140) / 3 = 140 件。

• 4 期移動平均:取第 3、4、5、6 月的 110、130、150、140。

• F7 = (110 + 130 + 150 + 140) / 4 = 132.5 件。

最終答案:3 期:140 件;4 期:132.5 件

觀念提醒:3 期平均較重視近期變化;4 期平均使用較長期間的資料,結果通常較平滑。

3. 加權移動平均法

某工廠最近 3 個月的需求分別為 200、240、260 件。公司決定使用加權移動平均法,給予由舊到新三期的權重 0.2、0.3、0.5。請預測下一個月的需求。如 果改為簡單移動平均,結果又是多少?使用公式 F_{t+1}=\sum_{i=1}^{n}w_iA_i

• 確認權重總和:0.2 + 0.3 + 0.5 = 1。

• 加權移動平均 = 0.2 × 200 + 0.3 × 240 + 0.5 × 260。

• = 40 + 72 + 130 = 242 件。

• 簡單移動平均 = (200 + 240 + 260) / 3 = 233.33 件。

最終答案:加權移動平均:242 件;簡單移動平均:約 233.33 件

觀念提醒:因為最近一期需求較高,加權移動平均給近期資料較高權重,因此預測值也較高。

4. 指數平滑法(連續三期)

某企業使用指數平滑法預測產品需求,平滑係數 α = 0.3。已知第 1 期預測值為 100 件,第 1、2、3 期實際需求分別為 120、130、110 件。請計算第 2、3、 4 期的預測值。使用公式 F_{t+1}=\alpha A_t+(1-\alpha)F_t

• 第 2 期:F2 = 0.3 × 120 + 0.7 × 100 = 106。

• 第 3 期:F3 = 0.3 × 130 + 0.7 × 106 = 113.2。

• 第 4 期:F4 = 0.3 × 110 + 0.7 × 113.2 = 112.24。

最終答案:F2 = 106;F3 = 113.2;F4 = 112.24 件

觀念提醒:每一期都必須使用前一期預測值及前一期實際值。不可直接將所有實際需求加權平均。

5. 綜合計算與預測方法比較

某公司 1 至 5 月實際需求為 100、120、110、150、140 件。請使用四種方法預測第 6 月需求:(1) Naïve;(2) 3 期簡單移動平均;(3) 3 期加權移動平均,權 重由舊到新為 0.2、0.3、0.5;(4) 指數平滑,α = 0.4,已知第 5 月預測值 F5 = 125。最後比較四種方法的結果。

使用公式:F_{t+1}=A_t\quad;\quad F_{t+1}=\frac{\sum A}{n}\quad;\quad F_{t+1}=\sum w_iA_i\quad;\quad F_{t+1}=\alpha A_t+(1-\alpha)F_t

• Naïve:F6 = A5 = 140 件。

• 3 期移動平均:F6 = (110 + 150 + 140) / 3 = 133.33 件。

• 加權移動平均:F6 = 0.2 × 110 + 0.3 × 150 + 0.5 × 140 = 137 件。

• 指數平滑:F6 = 0.4 × 140 + 0.6 × 125 = 131 件。

最終答案:Naïve:140;移動平均:133.33;加權移動平均:137;指數平滑:131 件

觀念提醒:四種方法使用的資訊與權重不同,因此預測結果不同。僅憑本題無法判定哪種方法最準確;需要實際需求與歷史預測誤差才能評估。

4. 考前計算公式速查

預測方法                              考試解題重點
Naı̈ve                  直接使用上一期實際需求
簡單移動平均                  取最近 n 期實際值,除以 n
加權移動平均                  每期實際值乘對應權重,權重總和為 1

計算題最容易失分的三個地方: 混淆實際值 與預測值 、移動平均取錯期數,以及指數平滑計算連續多期時,沒有正確使用上一期的預測結果。
